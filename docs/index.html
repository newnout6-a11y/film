      Куки YouTube (если упирается в «Sign in to confirm…») YouTube блокирует runner GitHub-Actions как бота. Решается экспортом своих куков.

      Поставь расширение «Get cookies.txt LOCALLY» (Chrome) или «cookies.txt» (Firefox), залогинься на youtube.com, нажми кнопку расширения → «Export» / «Сохранить как cookies.txt». Содержимое файла → в поле ниже. Шифруется в браузере и кладётся в секрет YT_COOKIES.

      Логины трекеров (для поиска) Без логина доступен только Pirate Bay. Остальные трекеры требуют учётку — оставь пустым то, чем не пользуешься.

      Каждый логин шифруется в браузере (libsodium sealed box) и кладётся в GitHub Secrets отдельной парой *_USERNAME / *_PASSWORD. Сначала «Сохранить» выше — нужны репо и токен.
