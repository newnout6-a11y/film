GitHub
Работает на раннерах GitHub Actions

Закинь любой файл к себе на Drive. Через гигабитный канал.

Вставь ссылку, нажми «Закинуть». Раннер GitHub Actions скачает файл на быстром канале и зальёт его на твой Google Drive — оттуда можно смотреть стримом, не загружая свой интернет.
